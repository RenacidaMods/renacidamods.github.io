Fatal Racing on a modern PC: 4K, widescreen and high frame rates

Short answer: play it with ROLLER, a free open source rebuild of the game by the FatalDecomp team, using a disc image of your own retail DOS copy.

It brings up to 4K, Hor+ widescreen, high frame rates at the correct game speed, anti-aliasing and the original CD music, on Windows, Linux, macOS and Android.

How to set it up

  1. Download the latest nightly for your system from ROLLER's releases. There's no stable release yet.
  2. Make a disc image of your Fatal Racing or Whiplash CD. A CUE/BIN image keeps the CD music; an ISO doesn't.
  3. Start ROLLER. On first launch it asks for the disc image and copies out the game data it needs.
  4. Press the ` key (above Tab) to open the settings overlay. For a 4K screen, a Render Scale option marked "(native)" gives widescreen, then pick an MSAA level.

Already have the game installed? ROLLER can use an existing folder with --whiplash-root.

Good to know

  • Only nightly pre-releases so far, so expect changes.
  • Most settings live in the debug overlay rather than the game's menus.
  • The HUD and menus stay at their original low resolution.
  • Keyboard steering ramps up gradually, as in the original.

Questions

What's the best way to play Fatal Racing on a modern PC?

Use ROLLER with a disc image of your own retail DOS copy. It runs on Windows, Linux, macOS and Android, at up to 4K, with Hor+ widescreen, high frame rates and the original CD music.

Does it run at high frame rates without speeding up?

Yes. The race runs on its own fixed 36 Hz timer, so the game speed stays correct at any frame rate. According to ROLLER's source code, motion between game steps isn't smoothed, so movement may still update 36 times a second.

Does it play the CD music?

Yes, from a CUE/BIN disc image, which includes the audio tracks. An ISO has none, so ROLLER falls back to MIDI.

Can I play it in a browser?

Yes, at fatal.racing, with the free Whiplash demo or a disc image of your own copy.

Does it include the game?

No. You need your own retail copy of Fatal Racing or Whiplash.
